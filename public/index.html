反馈收件箱

    接入与诊断

    这些是当前真实生效的边界。空记录、缺失截图或不可用源码都会在收件箱里如实显示，不会被文案抹去。

    用户入口
    computer.mosoo.ai 内的支持面板。复用 Computer 登录身份，由 Computer 服务端验证后转发给 SMM；浏览器不传入用户 ID。
    调查模型
    Mosoo Agent API / GPT-5.6 Luna。
    自动 Explore
    用户提交反馈后自动开始 Explore；Agent 需要时会请求浏览器截图，用户在线选择标签页授权，可以拒绝。采集完成后立即停止共享。
    页面证据
    页面 SDK 的语义上下文：页面、是否可见错误、视口、浏览器与时区。不包含聊天内容、输入值、凭据或完整 DOM 回放。
    服务端日志
    按当前用户与失败请求隔离。Computer 签名的响应元数据（路由、状态、耗时）与通过 Cloudflare Tail Worker 采集的执行日志按同一请求 ID 关联；不包含请求正文、堆栈或容器全量日志。
    源码调查
    仅开发者可启动，独立于用户侧 Explore。读取与该反馈版本匹配的只读发布片段，不是诊断时的实时 GitHub 读取，也不能证明用户浏览器实际加载的版本。
